📡 REST API Specification

POST /predict

Send image as either multipart/form-data with field image or raw JPEG binary stream with Content-Type: image/jpeg.

cURL Command (Multipart Form) 
curl -X POST -F "image=@leaf.jpg" http://127.0.0.1:5000/predict
Python requests Example 
import requests

url = 'http://127.0.0.1:5000/predict'
with open('leaf.jpg', 'rb') as f:
    res = requests.post(url, files={'image': f})
print(res.json())

📷 ESP32-CAM Microcontroller Setup

Raw JPEG Stream

Connect an ESP32-CAM to your Wi-Fi and stream camera captures directly to this API on your local network.

Arduino / ESP32 C++ Snippet 
#include <WiFi.h>
#include <HTTPClient.h>
#include "esp_camera.h"

void sendLeafCapture() {
    camera_fb_t * fb = esp_camera_fb_get();
    if (!fb) return;

    HTTPClient http;
    // Replace with your computer's local IP address
    http.begin("http://192.168.1.100:5000/predict");
    http.addHeader("Content-Type", "image/jpeg");

    int httpCode = http.POST(fb->buf, fb->len);
    String response = http.getString();
    Serial.println(response);

    http.end();
    esp_camera_fb_return(fb);
}
